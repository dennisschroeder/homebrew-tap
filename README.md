# homebrew-tap

Homebrew tap for tools by dennisschroeder. Formulae and casks are generated by GoReleaser on release.

| Tool | Install |
|---|---|
| [Throughline](https://github.com/dennisschroeder/throughline) | `brew install dennisschroeder/tap/throughline` |
| [langdock-mcp](https://github.com/dennisschroeder/langdock-mcp) | `brew install --cask dennisschroeder/tap/langdock-mcp` |
